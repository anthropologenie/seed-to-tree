Job hunting tracker with ML-powered job matching, application pipeline 
management, and interview preparation tools.

**Status**: Production (100% test pass rate)
**Tech**: Python, SQLite, Flask
**Integration**: Provides training data for Sacred QA Parliament

## Symbiotic Integration

The two projects form a **bidirectional learning system**:
```
Parliament (Intelligence) ↔ Jobs DB (Reality)
     Advisory              ←→    Training
```

**Direction 1**: Parliament advises on jobs using real skill/history data  
**Direction 2**: Job outcomes train Parliament for continuous improvement
